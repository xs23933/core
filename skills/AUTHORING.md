# Agent 文档编写标准

本标准用于逐步整理主题文档，本次先覆盖 Handler/Ctx；其它主题仍按需读取现有文档。

1. AGENTS 只放工作入口、硬边界、验证与交付；AI_CONTEXT 只放跨任务速查。
2. skill 按「适用任务 → 必须遵守 → 最小完整示例 → 易错边界 → 验证与深入」组织。
3. 指针同时说明何时读取与读取什么。只加载当前任务分支；完整参考不是必读前置。
4. 示例优先链接真实可编译文件；片段标明缺少的装配与用途，不伪装完整应用。
5. 详细合同在完整参考维护；短入口仅保留关键规则和链接。签名/行为变化同步相关短规则与示例。
6. 生成包从权威规则与真实源码提取，不手工维护副本；修改源后重新生成并检查。
7. 预算以目标模型 tokenizer 实测为准；字符/字节数不冒充 token 数。给任务、工具结果和回答留空间。
8. 文档调整检查路径、API、生成漂移及示例测试；记录模型效果评测和静态验证的区别。

完整资料保留在 AI_CONTEXT_REFERENCE.md 与各 *-reference.md；这些是按需维护的参考，不是历史归档。
